# @morphicblocks/themes

Ready-made themes for the code views of [Morphic Blocks](https://morphicblocks.com).

```bash
npm install @morphicblocks/themes
```

```ts
import { standard } from "@morphicblocks/themes";

engine.mount({ codespaceContainer, editorTheme: standard.light });
```

Families: `standard` (`light`, `dark`, based on VS Code's Light+ and Dark+). See the [themes guide](https://docs.morphicblocks.com/guides/themes/) for more.
